# Benchmark-for-Real-World-Logical-Contradiction-Detection-with-LLMs
Leandro Duarte's Master's Thesis - A Benchmark for Real-World Logical Contradiction Detection with Large Language Models


## /ProtConKG
Here, the ProtConKG is generated by fusing the Gene Ontology, proteins, and positive and negative annotations from proteins to GO classes. It is then used to extract direct and hierarchically inferred contradictions and their respective counterparts.

## /cardinality_constraint
Extraction of cardinality constrained contradictions from Wikidata using single-value constraints. Their counterparts are also extracted by using multi-value properties.

## /disjoint_axiom
Extraction of disjoint class and disjoint instance contradictions as well as their counterparts.

## /verbalization
This code uses predefined templates to transform knowledge graph triples into statements. This is done in three different languages: English, French, and Spanish

## /llm_eval
The final verbalized datasets are used here to test a variety of open-source models using Hugging Face. Their outputs are extracted, and consequently their metrics are calculated.
